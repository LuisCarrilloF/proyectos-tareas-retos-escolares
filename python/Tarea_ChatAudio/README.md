# Instrucciones
Acabo de encontrar este proyecto dentro de algunas carpets, se debe instalar playsound con el siguiente comando:
```
pip install playsound
```
Este proyecto, si mal lo recuerdo lo hice como en tercer semestre, despúes del otro, ya que estabamos aprendiendo la logica de web-sockets.
En este punto es un chat `per to per`. La razon por la que hice otra carpeta es porque aun no aprendia a usar un controlador de versiones como `Git` y `Github`. Además de tener el problema del archivo `venv`.
