# Instrucciones
Acabo de encontrar este proyecto dentro de algunas carpets, se debe instalar playsound con el siguiente comando:
```
pip install playsound
```
Este proyecto, si mal lo recuerdo lo hice como en tercer semestre, ya que estabamos aprendiendo la logica de web-sockets.
Cabe la pena mencionar, que lo unico que hace es enviar a un servidor mensajes y debe sonar una notificación. Cabe la poena mencionar, que en ese entonces desconocia la existencia de un entorno virtual como lo es `venv`.
